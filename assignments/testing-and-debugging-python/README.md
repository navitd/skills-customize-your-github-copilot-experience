# 📘 Assignment: Testing and Debugging Python Functions

## 🎯 Objective

Practice writing a simple test with Python's built-in `assert` statement and using its result to find and fix a bug in a function.

## 📝 Tasks

### 🛠️ Test a Function

#### Description
Open the starter code and add an assertion that checks whether `double_number(2)` returns `4`. Run the program and observe the failed test.

#### Requirements
Completed program should:

- Include an assertion that expects `double_number(2)` to equal `4`
- Run the assertion and observe that it fails with the original function
- Use the assertion's expected and actual values to identify the bug


### 🛠️ Fix the Bug

#### Description
Correct `double_number` so it doubles its input, then run the program again.

#### Requirements
Completed program should:

- Return twice the input value from `double_number`
- Pass the assertion for the input `2`
- Print `All tests passed!` after the assertion succeeds
